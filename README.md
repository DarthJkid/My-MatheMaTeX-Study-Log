## Conventions

| Rule | Detail |
|------|--------|
| **Naming** | Lower-case, hyphen-separated (`unit-01-linear`, not `Unit 1 Linear`) |
| **No spaces** | Use `-` everywhere |
| **No "Final" versions** | Use Git tags/branches for versioning |
| **LaTeX engine** | [Tectonic](https://tectonic-typesetting.github.io/) |
| **Bibliography** | Single `bibliography/references.bib`; cite with `\cite{}` in LaTeX, `[@key]` in Markdown |
| **PDFs** | Auto-generated by CI; stored on the `pdf-exports` branch (not `main`) |

---

## Automated PDF Compilation

Every push to `main` that touches a `.tex` file triggers the
[`compile-latex`](.github/workflows/compile-latex.yml) workflow.
It compiles all `.tex` files with [Tectonic](https://tectonic-typesetting.github.io/)
and force-pushes the resulting PDFs to the `pdf-exports` branch,
keeping `main` free of heavy binary commits.

---

## Zettelkasten Notes

The [`notes/`](notes/) folder is concept-centric (not source-centric).
Files are named in `kebab-case-concept.md` and cross-linked with standard
Markdown links for full GitHub compatibility.

**Example cross-link** (from `notes/calculus/derivatives.md`):

> "The derivative is a linear operator, as defined in
> [linear-algebra/linear-transformations](linear-algebra/README.md)."
